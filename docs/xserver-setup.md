# qkobo.jp を Xserver で公開する手順

このサイト（19工房のテーマ）を、Xserver 上の `https://qkobo.jp/` で動かすまでの手順です。
上から順に進めます。所要は、DNS の反映待ちを除いて 30 分ほどです。

## いまの状態（2026年9月13日に確認）

| 項目 | 状態 |
|---|---|
| ドメイン `qkobo.jp` | **取得済み**（2026/09/09、お名前.com） |
| ネームサーバー | `dns1.onamae.com` / `dns2.onamae.com` — **まだお名前.com を向いています** |
| A レコード | `150.95.255.38` — お名前.com の仮ページ |

つまり、Xserver 側でドメインを追加しても、お名前.com のネームサーバーを Xserver に切り替えるまでは
`qkobo.jp` は Xserver に届きません。**手順1が最初です。**

---

## 1. お名前.com で、ネームサーバーを Xserver に切り替える

1. https://navi.onamae.com/ にログイン
2. 上のメニュー **ドメイン** → `qkobo.jp` の行の **ネームサーバー** 欄 → **変更する**
3. 「**他のネームサーバーを利用**」を選ぶ
4. ネームサーバーを次の5つにする

   ```
   ns1.xserver.jp
   ns2.xserver.jp
   ns3.xserver.jp
   ns4.xserver.jp
   ns5.xserver.jp
   ```

5. **確認画面へ進む** → **設定する**

> 反映には数時間かかることがあります（最大72時間。ふつうは1〜3時間）。
> 反映を待つあいだに、手順2〜4を先に進めて構いません。

反映されたかどうかは、Mac のターミナルで確かめられます。

```bash
dig +short qkobo.jp NS
```

`ns1.xserver.jp.` のように Xserver の名前が返ってくれば反映済みです。

---

## 2. Xserver に qkobo.jp を追加する

1. https://secure.xserver.ne.jp/xapanel/login/xserver/server/ から **サーバーパネル** にログイン
2. **ドメイン** → **ドメイン設定** → タブ **ドメイン設定追加**
3. ドメイン名に `qkobo.jp` と入れる
4. 次の2つに **チェックを入れたまま**
   - ☑ 無料独自SSLを利用する（推奨）
   - ☑ 高速化・アクセス数拡張機能「Xアクセラレータ」を有効にする（推奨）
5. **確認画面へ進む** → **追加する**

> 「無料独自SSLの設定に失敗しました」と出た場合は、手順1の反映がまだです。
> 反映を待ってから、**SSL設定** → `qkobo.jp` → **独自SSL設定追加** でやり直せます。

これで、サーバー上に `/home/（サーバーID）/qkobo.jp/public_html/` ができます。

---

## 3. WordPress を入れる

1. サーバーパネル → **WordPress** → **WordPress簡単インストール**
2. ドメインの一覧から `qkobo.jp` の **選択する**
3. タブ **WordPressインストール** で、次のように入れる

   | 項目 | 入れる内容 |
   |---|---|
   | サイトURL | `qkobo.jp` のまま。右の欄は**空欄**（ルートに入れる） |
   | ブログ名 | `19工房`（あとから変えられます） |
   | ユーザー名 | 管理画面のログイン名。`admin` は避ける |
   | パスワード | 管理画面のパスワード。**自分で決めて控えておく** |
   | メールアドレス | `tapes-penne05@icloud.com` |
   | キャッシュ自動削除 | ON |
   | データベース | 自動でデータベースを生成する |
   | テーマ | **WordPressデフォルトテーマ**（あとで差し替えます） |

4. **確認画面へ進む** → **インストールする**
5. 出てきた **管理画面 URL・ユーザー名・パスワード** を控える

> ここで決めたパスワードは、私（Claude）には渡さないでください。
> 以降の手順で必要なのは、ご自身が管理画面にログインすることだけです。

---

## 4. SSL（https）を確かめる

手順1の反映後、10分〜1時間で SSL が有効になります。

1. サーバーパネル → **SSL設定** → `qkobo.jp` を選ぶ
2. `qkobo.jp` の行に **反映済み** と出ていればOK

3. WordPress の管理画面（`https://qkobo.jp/wp-admin/`）にログイン
4. **設定** → **一般** で、次の2つを `https://qkobo.jp` にする
   - WordPress アドレス (URL)
   - サイトアドレス (URL)
5. **変更を保存**（一度ログアウトされるので、再ログイン）

> Xserver は「**http → https へのリダイレクト**」もサーバーパネルから入れられます。
> **SSL設定** → `qkobo.jp` → タブ **Webサイトの常時SSL化** → **ONにする**。

---

## 5. テーマを入れる

**A. 管理画面から入れる（かんたん）**

1. 管理画面 → **外観** → **テーマ** → **新規追加** → **テーマのアップロード**
2. このフォルダの `kobo19.zip` を選んでインストール
3. **有効化**

**A'. ファイルマネージャから入れる（管理画面に入れないとき）**

1. サーバーパネル上部の **ファイルマネージャ** → `qkobo.jp/public_html/wp-content/themes/` を開く
2. **アップロード** で `kobo19.zip` を上げる
3. 上がった `kobo19.zip` を選んで **展開**。`themes/kobo19/` ができます
   （ZIP は中身を直に入れてあるので、ファイルマネージャが ZIP 名のフォルダを作ってちょうど収まります）
4. 残った `kobo19.zip` は消して構いません
5. 管理画面 → **外観** → **テーマ** で **Q工房** を有効化

有効化した瞬間に、次のものが自動で作られます。

- アプリ **SujiCalc**（情報とデモつき）
- 資料 14件（説明書 11章／サポート／プライバシーポリシー／利用規約）
- トップページの設定

4. **設定** → **パーマリンク** を開いて、そのまま **変更を保存**（`/apps/…` `/docs/…` の URL を有効にする）

**B. SSH で入れる（今後の更新が楽）**

テーマを直すたびに ZIP を作ってアップロードするのは手間なので、SSH でつなげるようにしておくと
コマンド1つで反映できます。

1. サーバーパネル → **SSH設定** → タブ **SSH設定** → **ONにする**
2. タブ **公開鍵認証用鍵ペアの生成** → パスフレーズを決めて **生成する** → 秘密鍵（`（サーバーID）.key`）をダウンロード
3. Mac で、鍵を置いて権限を締める

   ```bash
   mkdir -p ~/.ssh
   mv ~/Downloads/（サーバーID）.key ~/.ssh/xserver_qkobo.key
   chmod 600 ~/.ssh/xserver_qkobo.key
   ```

4. このフォルダに `.deploy.env` を作る（`.deploy.env.example` を写して埋める）

   ```
   XSERVER_ID=xs123456              ← サーバーID（サーバーパネル右上に出ている英数字。SSH のユーザー名でもあります）
   XSERVER_HOST=sv12345.xserver.jp  ← ホスト名（サーバーパネル → サーバー情報 の「ホスト名」）
   XSERVER_KEY=~/.ssh/xserver_qkobo.key
   XSERVER_DOMAIN=qkobo.jp
   ```

5. 反映する

   ```bash
   ./deploy-xserver.sh
   ```

   初回は「テーマがまだ有効化されていない」ので、反映後に管理画面 → 外観 → テーマ で **19工房** を有効化してください。

`.deploy.env` と秘密鍵は Git に入りません（`.gitignore` に入れてあります）。

## 6. 公開前に確かめること

- [ ] `https://qkobo.jp/` でトップが出る（SujiCalc のカードと「SujiCalc を見る」ボタン）
- [ ] `https://qkobo.jp/apps/sujicalc/` で製品ページが出る
- [ ] `https://qkobo.jp/docs/sujicalc-support/` でサポートが出る
- [ ] `https://qkobo.jp/docs/sujicalc-privacy/` でプライバシーポリシーが出る
- [ ] **設定** → **表示設定** → 「検索エンジンがサイトをインデックスしないようにする」の **チェックが外れている**
- [ ] **外観** → **カスタマイズ** → **サイトの設定** の連絡先メールアドレスが正しい
- [ ] 管理画面のユーザー名・パスワードを控えてある

---

## 7. App Store Connect に登録する URL

サイトが出るようになったら、App Store Connect の SujiCalc の App 情報に、次を入れます。

| 項目 | URL | 必須 |
|---|---|---|
| **サポート URL** | `https://qkobo.jp/docs/sujicalc-support/` | 必須 |
| **プライバシーポリシー URL** | `https://qkobo.jp/docs/sujicalc-privacy/` | 必須 |
| マーケティング URL | `https://qkobo.jp/apps/sujicalc/` | 任意 |

これまで暫定で GitHub Pages の URL を入れていた場合は、こちらに差し替えてください。

## 困ったとき

**`qkobo.jp` を開いてもお名前.com の画面が出る**
→ 手順1の反映待ちです。`dig +short qkobo.jp NS` で `xserver.jp` が返るまで待ちます。

**「このサイトは安全ではありません」と出る**
→ SSL がまだです。手順4で **反映済み** になるまで待ちます。反映後もブラウザが古い状態を覚えていることがあるので、シークレットウインドウで開き直します。

**テーマを有効化したのにトップが変わらない**
→ **設定** → **表示設定** → 「ホームページの表示」が **固定ページ** で、ホームページに「19工房」（または「home」）が選ばれているか確認します。

**`/apps/sujicalc/` が 404 になる**
→ **設定** → **パーマリンク** を開いて、そのまま **変更を保存**。

**SujiCalc や説明書が入っていない**
→ テーマ有効化時に一度だけ入る仕組みです。入り直したいときは、プラグイン **WP-CLI** か phpMyAdmin で
`wp_options` の `kobo19_starter_installed` を削除して、テーマを別のものに切り替え → 19工房に戻します。
