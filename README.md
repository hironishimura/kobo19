# SujiCalc — 公開用サイト

macOS / iOS アプリ **SujiCalc** を公開・案内するための WordPress サイト一式です。
アプリの紹介、11章の説明書、サポート、プライバシーポリシー、利用規約が入っています。

## App Store Connect に登録する URL

App Store Connect では **サポート URL** と **プライバシーポリシー URL** が必須です。
このサイトを公開したら、次の URL を登録してください。

| 項目 | URL | 必須 |
|---|---|---|
| サポート URL | `https://（サイトのアドレス）/support/` | 必須 |
| プライバシーポリシー URL | `https://（サイトのアドレス）/privacy/` | 必須 |
| マーケティング URL | `https://（サイトのアドレス）/` | 任意 |

WordPress をまだ立てていない場合、上のプレビュー（GitHub Pages）の URL を暫定で
登録することもできます。ただし `noindex` が付いているので、正式公開時には
WordPress 側の URL に差し替えてください。

**使用許諾契約**は、App Store Connect の既定（Apple の標準 EULA）のままで構いません。
アプリ内の初回起動時に利用規約の同意を取っているためです。より明確にしたい場合は、
[preview/terms.html](preview/terms.html) と同じ文面をカスタム使用許諾契約として貼れます。

**App のプライバシー**は「**データを収集しません**（Data Not Collected）」を選びます。
ネットワーク通信なし・解析なし・広告なしで、書類は利用者自身の iCloud にのみ保存されるためです。

## 設置のしかた

### 1. WordPress を用意する

レンタルサーバーの管理画面などからインストールします。PHP 8.0 以上が必要です。

### 2. テーマを入れる

**管理画面から入れる場合**

1. 管理画面 → 外観 → テーマ → 新規追加 → テーマのアップロード
2. `kobo19.zip` を選んでインストール
3. 「有効化」を押す

**FTP で入れる場合**

`wordpress/wp-content/themes/kobo19/` フォルダごと、サーバーの `wp-content/themes/` に
アップロードしてから、管理画面で有効化します。

### 3. 有効化したときに用意されるもの

- **説明書 11章** — はじめに／基本の書きかた／単位／名前と参照／表と文字／関数と定数／グラフ／プログラム／シートと同期／キーパッドと設定／ショートカット一覧
- **固定ページ 3枚** — サポート／プライバシーポリシー／利用規約
- **トップページの設定** — front-page.php が使われる状態に切り替わります

すでに同じスラッグのページがある場合は、上書きされません。

### 4. パーマリンクを更新する

管理画面 → 設定 → パーマリンク を開いて、そのまま「変更を保存」を押します。
説明書のページの URL（`/manual/…`）が有効になります。

### 5. アプリの情報を入れる

管理画面 → 外観 → カスタマイズ → **アプリの情報** で、次を設定します。

| 項目 | 内容 |
|---|---|
| アプリの名前 | SujiCalc |
| 一行の説明 | 打つと右に答えが出る、ノート型の電卓。 |
| トップの説明文 | ヒーローの本文 |
| **App Store の URL** | 審査通過後に入れると、トップとメニューに「App Store で見る」ボタンが出ます |
| 価格の表示 | 空欄なら出ません |
| バージョン／対応する OS／カテゴリ | トップの一覧に出ます |
| 連絡先メールアドレス | フッターとサポートページに出ます |

### 6. メニューを設定する（任意）

外観 → メニュー で作って「ヘッダーのメニュー」に割り当てます。
設定しない場合は、使い方・サポート・プライバシー（と、URL があれば App Store）が自動で並びます。

## 説明書を書き足す・直す

管理画面の左メニューに **「説明書」** があります。1章が1件の投稿です。

**並び順**は「ページ属性 → 順序」の数字で決まります。小さい数字が上（先の章）です。
章番号（01、02…）は並び順から自動で振られるので、順序を入れ替えれば番号も付け直されます。

**抜粋**に一文書いておくと、目次に説明として出ます。

### 本文で使える書き方

アプリの画面と同じ「左に式・右に答え」の形で例を見せられます。**計算ノート**のショートコードです。

```
[calc]
単価 = 1200円 | 1,200円
個数 = 35 | 35
単価 * 個数 | 42,000円
[/calc]
```

- 縦棒（`|`）の左が式、右が答えです
- 答えの出ない行は縦棒ごと省きます
- エラーの例は `式 |! メッセージ` と書くと、答えが朱色になります
- `[calc numbers="no"]` で行番号を消せます
- `[calc label="見出し"]` で上に小さな見出しを付けられます

そのほかのショートコード。

| 書き方 | 出るもの |
|---|---|
| `[key]⌘Z[/key]` | キーの表記 |
| `[note]…[/note]` | 囲みの覚え書き |
| `[note title="見出し"]…[/note]` | 見出し付きの覚え書き |

## このサイトの決まりごと

**例はアプリの画面と同じ形で見せます。** 行番号があって、左に式、右に答えが並ぶ。
説明の文章を読まなくても、形を見れば何が起きるか分かるようにしています。
答えは罫書きの青、エラーは朱で、アプリの色分けと同じ考えかたです。

背景の方眼と外枠は、方眼のノートに式を書く、というアプリの姿から取っています。

配色は白黒の製図をもとにした4色だけです。紙のグレー、鉛筆の黒、罫書きの青、
見当合わせの朱。OS がダークモードのときは、色が自動で夜側に切り替わります。

### 文章を直すとき

すでに WordPress に入れたあとは、**管理画面から直してください。**
`inc/starter-manual.php` は「はじめて有効化したときに入れる文章」なので、
ここを直しても登録済みの記事には反映されません。

まだ入れていない段階なら、`inc/starter-manual.php` を直してから有効化するのが早いです。
プレビューは `php build-preview.php` で作り直せます。

### 初期データを入れ直したいとき

一度だけ登録され、以後は追加されません。入れ直す場合は、データベースのオプション
`kobo19_starter_installed` を削除してから、テーマを切り替え直してください。

### 2つ目のアプリを載せるとき

いまはトップページが SujiCalc の製品ページになっています。アプリが増えたときは、
トップにアプリの一覧を置き、アプリごとに製品ページと説明書を持たせる形が素直です。
説明書の投稿タイプに「どのアプリのものか」の項目を足すことになります。
