# 19工房 — アプリ公開用サイト

つくったアプリを公開・案内するための WordPress サイト一式です。
アプリを1本ずつ登録すると、それぞれに **製品ページ・説明書・サポート・プライバシーポリシー・利用規約**
を持たせられます。いまは **SujiCalc** が1本入っています。

## しくみ

投稿タイプは2つだけです。

| 種類 | 中身 | URL |
|---|---|---|
| **アプリ** | 1本＝1件。名前・App Store の URL・バージョンなど | `/apps/{アプリ}/` |
| **資料** | 説明書の章／サポート／プライバシーポリシー／利用規約 | `/docs/{スラッグ}/` |

資料は必ず「**どのアプリのものか**」と「**種別**」を持ちます。だからアプリが増えても、
説明書もサポートもアプリごとに分かれたまま増えていきます。

**トップページはアプリの数で自動的に変わります。**

- 1本のとき — そのアプリの製品ページがそのままトップになります
- 2本以上のとき — アプリの一覧に切り替わります（設定は要りません）

## アプリを追加する

### 1. アプリを登録する

管理画面 → **アプリ** → 新規追加。

タイトルがアプリ名です。本文には「できること」を書きます（`[calc]` などのショートコードが使えます）。
本文の下の **アプリの情報** に、次を入れます。

| 項目 | 内容 |
|---|---|
| 一行の説明 | アプリ名のすぐ下に出ます |
| 説明文 | その下に出る2〜3行 |
| **App Store の URL** | 入れると「App Store で見る」ボタンが出ます。審査が通ってからで構いません |
| バージョン／対応する OS／カテゴリ／価格 | 名前の下の一覧に出ます。空欄の項目は出ません |
| 状態 | 公開中・審査中・準備中・制作中。一覧に小さな印として出ます |
| トップに出すデモ | `[calc]` のショートコードをそのまま書けます |

**アイキャッチ画像**を設定すると、アプリ一覧でアイコンとして出ます。

**並び順**は「ページ属性 → 順序」の数字。小さいほど先に出ます。

### 2. 説明書とサポートを足す

管理画面 → **資料** → 新規追加。右側の「この資料について」で、

- **どのアプリの資料か** — さきほど登録したアプリを選びます
- **種別** — 説明書の章／サポート／プライバシーポリシー／利用規約

「説明書の章」だけが目次に並び、章番号（01、02…）が自動で付きます。順番は「ページ属性 → 順序」です。

**スラッグはアプリ名で始めておくと安全です**（`sujicalc-basics` のように）。
アプリが増えても、同じ章名で衝突しません。

### 3. App Store Connect に URL を登録する

**サポート URL とプライバシーポリシー URL は、アプリごとに必須**です。
資料を登録すると、次の形の URL ができます。

| 項目 | URL の例 | 必須 |
|---|---|---|
| サポート URL | `https://（サイト）/docs/sujicalc-support/` | 必須 |
| プライバシーポリシー URL | `https://（サイト）/docs/sujicalc-privacy/` | 必須 |
| マーケティング URL | `https://（サイト）/apps/sujicalc/` | 任意 |

**使用許諾契約**は App Store Connect の既定（Apple の標準 EULA）のままで構いません。
SujiCalc はアプリ内の初回起動時に利用規約の同意を取っているためです。
より明確にしたい場合は、利用規約の資料と同じ文面をカスタム使用許諾契約として貼れます。

**App のプライバシー**は「**データを収集しません**（Data Not Collected）」を選びます。
SujiCalc はネットワーク通信なし・解析なし・広告なしで、書類は利用者自身の iCloud にのみ
保存されるためです。**アプリごとに事情が違うので、新しいアプリでは必ず確認してください。**

## 設置のしかた

### 1. WordPress を用意する

レンタルサーバーの管理画面などからインストールします。PHP 8.0 以上が必要です。

### 2. テーマを入れる

管理画面 → 外観 → テーマ → 新規追加 → テーマのアップロードで `kobo19.zip` を選び、有効化します。
FTP の場合は `wordpress/wp-content/themes/kobo19/` フォルダごとアップロードしてから有効化します。

### 3. 有効化したときに用意されるもの

- **アプリ 1件** — SujiCalc（情報とデモつき）
- **資料 14件** — 説明書 11章＋サポート／プライバシーポリシー／利用規約
- **トップページの設定** — front-page.php が使われる状態に切り替わります

すでに同じスラッグのものがある場合は、上書きされません。

### 4. パーマリンクを更新する

管理画面 → 設定 → パーマリンク を開いて、そのまま「変更を保存」を押します。
`/apps/…` と `/docs/…` の URL が有効になります。

### 5. サイトの設定

外観 → カスタマイズ → **サイトの設定** で、連絡先メールアドレスと、
アプリが2本以上になったときのトップの見出しを設定します。
アプリ個別の情報は、それぞれのアプリの編集画面で入れます。

### 6. メニューを設定する（任意）

外観 → メニュー で作って「ヘッダーのメニュー」に割り当てます。設定しない場合は自動で並びます。

- アプリが1本のとき — 使い方・サポート・プライバシー（と、URL があれば App Store）
- 2本以上のとき — アプリ・説明書とサポート

## 本文で使える書き方

アプリの画面と同じ「左に式・右に答え」の形で例を見せられます。**計算ノート**のショートコードです。

```
[calc]
単価 = 1200円 | 1,200円
個数 = 35 | 35
単価 * 個数 | 42,000円
[/calc]
```

- 縦棒（`|`）の左が式、右が答えです
- 答えの出ない行は縦棒ごと省きます
- エラーの例は `式 |! メッセージ` と書くと、答えが朱色になります
- `[calc numbers="no"]` で行番号を消せます
- `[calc label="見出し"]` で上に小さな見出しを付けられます

| そのほか | 出るもの |
|---|---|
| `[key]⌘Z[/key]` | キーの表記 |
| `[note]…[/note]` | 囲みの覚え書き |
| `[note title="見出し"]…[/note]` | 見出し付きの覚え書き |

## このサイトの決まりごと

**例はアプリの画面と同じ形で見せます。** 行番号があって、左に式、右に答えが並ぶ。
説明の文章を読まなくても、形を見れば何が起きるか分かるようにしています。
答えは罫書きの青、エラーは朱です。

**地は無地です。** 背景に方眼を敷いていた時期がありますが、方眼の間隔は本文の行送りと揃わず、
文字の下を線が横切って読みにくくなるためやめました。線を引くのは、行と1対1で対応する
計算ノートと表だけです。

配色は白黒の製図をもとにした4色だけです。紙のグレー、鉛筆の黒、罫書きの青、見当合わせの朱。
OS がダークモードのときは、色が自動で夜側に切り替わります。

## 技術的なこと

- **プラグインは不要です。** 投稿タイプもカスタムフィールドもショートコードもテーマ内で完結しています
- 外部から読み込むのは Google Fonts（Zen Kaku Gothic New / IBM Plex Mono）だけです

```
kobo19/

├── theme.json             ブロックエディタの色と書体
├── functions.php          読み込みと基本設定
├── front-page.php         トップ（アプリ1本なら製品ページ、2本以上なら一覧）
├── archive-app.php        アプリ一覧
├── single-app.php         アプリの製品ページ
├── archive-doc.php        説明書とサポートの一覧（アプリごと）
├── single-doc.php         資料のページ（章なら左に目次と前後送り）
├── page.php / single.php / index.php / 404.php / searchform.php
├── header.php / footer.php
├── inc/
│   ├── cpt.php            投稿タイプ「アプリ」「資料」の登録
│   ├── meta-box.php       アプリの情報／資料の紐づけの入力欄
│   ├── shortcodes.php     [calc] [key] [note]
│   ├── template-tags.php  アプリと資料をつなぐ関数、章番号、目次
│   ├── customizer.php     サイト全体の設定
│   ├── demo-content.php   文章をブロックに変換して登録する
│   ├── starter-app.php    最初のアプリ（SujiCalc）の内容
│   ├── starter-manual.php 説明書 11章の文章
│   └── starter-pages.php  サポート・プライバシー・規約の文章
└── template-parts/
    ├── app-hero.php       アプリの見出し（トップと製品ページで共通）
    ├── app-card.php       アプリのカード（一覧用）
    └── app-docs.php       アプリに紐づく資料の一覧
```

### 文章を直すとき

すでに WordPress に入れたあとは、**管理画面から直してください。**
`inc/starter-*.php` は「はじめて有効化したときに入れる文章」なので、
ここを直しても登録済みの記事には反映されません。

まだ入れていない段階なら、`inc/starter-*.php` を直してから有効化するのが早いです。
プレビューは `php build-preview.php` で作り直せます。

### 初期データを入れ直したいとき

一度だけ登録され、以後は追加されません。入れ直す場合は、データベースのオプション
`kobo19_starter_installed` を削除してから、テーマを切り替え直してください。
