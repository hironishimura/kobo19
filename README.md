制作物（ホームページ・プログラム・プロダクツ）を紹介するWordPressサイト一式です。

**https://hironishimura.github.io/kobo19/**

## 設置のしかた

### 1. WordPressを用意する

レンタルサーバーの管理画面などからWordPressをインストールします。PHP 8.0以上が必要です。

### 2. テーマを入れる

**管理画面から入れる場合（かんたん）**

1. 管理画面 → 外観 → テーマ → 新規追加 → テーマのアップロード
2. `kobo19.zip` を選んでインストール
3. 「有効化」を押す

**FTPで入れる場合**

`wordpress/wp-content/themes/kobo19/` フォルダごと、サーバーの `wp-content/themes/` にアップロードしてから、管理画面で有効化します。

### 3. 有効化したときに用意されるもの

テーマを有効化すると、次のものが自動で作られます。

- **区分3つ** — ホームページ / プログラム / プロダクツ
- **制作物13点** — 実際の制作物を登録済み（内容は編集できます）
- **固定ページ2枚** — 工房について / 相談する
- **トップページの設定** — front-page.php が使われる状態に切り替わります

すでに区分や制作物がある場合は、上書きされません。

### 4. パーマリンクを更新する

管理画面 → 設定 → パーマリンク を開いて、そのまま「変更を保存」を押します。制作物ページのURLが有効になります。

### 5. メニューを設定する

管理画面 → 外観 → メニュー でメニューを作り、「ヘッダーのメニュー」に割り当てます。
設定しない場合は、制作物・区分3つ・工房について・相談する が自動で並びます。

## 制作物を追加・編集する

管理画面の左メニューに **「制作物」** が増えています。

新規追加すると、本文の下に **表題欄** の入力欄があります。図面の表題欄と同じ項目です。

| 項目 | 入れるもの | 例 |
|---|---|---|
| 図番 | 通し番号 | `W-03` |
| 年 | 制作した年 | `2026` |
| 材料 | 使った技術をスラッシュ区切り | `WordPress / PHP / 自作テーマ` |
| 状態 | 公開中・運用中・設計中など | `公開中` |
| リンク | 公開先やリポジトリのURL | `https://…` |
| リンクの文言 | ボタンに出す言葉 | `サイトを見る` |
| 施主 | 依頼元。自主制作なら空欄 | `株式会社◯◯` |

**図番** は空欄でも構いません。空欄のときは、区分の頭文字（ホームページ=W／プログラム=P／プロダクツ=D）と並び順から自動で組み立てます。

**抜粋** に一文だけ書いておくと、一覧カードの説明文になります。空欄なら本文の冒頭が使われます。

### 並び順

トップページも一覧ページも、**新しい順に一列**で並びます。区分では分けません。

順番は「ページ属性 → 順序」の数字で決まります。

- **数字が小さいものが上**に来ます
- 数字が同じときは、**投稿日が新しいもの**が先に来ます
- 新規追加した制作物は順序が `0` なので、何も入れなければ自動で一番上に並びます

初期データは、実際の最終更新が新しい順に 1〜13 を振ってあります。特定の制作物を上に固定したいときは、その順序を小さい数字（`0` など）に書き換えてください。

トップページに出るのは上位12点で、13点目からは一覧ページに続きます。

**サムネイル画像** を設定すると、カードの上部に表示されます。設定しない制作物は、区分ごとに角度の違うハッチング（斜線）で埋まります。

## 文言を変える

管理画面 → 外観 → カスタマイズ → **19工房の設定** から、次の文言を変えられます。

- トップの小見出し・見出し・説明文
- フッターの「相談する」の見出しと説明文
- 連絡先メールアドレス
- 開設年

サイト名とキャッチフレーズは「サイト基本情報」から変えられます。ロゴ画像を設定すると、`19` のマークの代わりに表示されます。

## このサイトの決まりごと

トップページは制作物を**新しい順に一列**で並べます。区分ごとに分けないのは、19工房でつくるものが毎回違う素材で、区分よりも「いま何をつくっているか」のほうが先に伝わるべきだからです。区分で絞り込みたいときは、ヘッダーのメニューか一覧ページの絞り込みを使います。

制作物のカードは、**図面の表題欄**の形をしています。右下に図番・区分・年が枠で仕切られて並ぶ、あの部分です。装飾ではなく、実際に入力した値がそのまま入ります。

サムネイル画像のない制作物は、**区分ごとに角度の違うハッチング**で埋めます。図面のハッチングが材料の違いを表すのと同じ扱いです。

- ホームページ … 45°
- プログラム … −45°
- プロダクツ … 垂直

配色は白黒の製図をもとにしています。紙のグレー、鉛筆の黒、罫書きの青、見当合わせの朱の4色だけです。OSがダークモードのときは、色が自動で夜の製図板側に切り替わります。

## 技術的なこと

- **プラグインは不要です。** カスタム投稿タイプもカスタムフィールドもテーマ内で完結しています
- 外部から読み込むのは Google Fonts（Zen Kaku Gothic New / IBM Plex Mono）だけです
- 記事一覧（お知らせ）を使う場合は、固定ページを1枚作って「設定 → 表示設定 → 投稿ページ」に指定してください
- 問い合わせフォームを置く場合は、「相談する」の固定ページに、お使いのフォームプラグインのブロックを挿入してください

### 初期データを入れ直したいとき

デモの13点は一度だけ登録され、以後は追加されません。消してもう一度入れ直したい場合は、データベースのオプション `kobo19_demo_installed` を削除してから、テーマを切り替え直してください。
